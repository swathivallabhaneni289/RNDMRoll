# Phase 5: Validation Map (Friend Feed: friends, the Board, reactions, comments, notifications)

> How each behaviour is proven. PHASE 5. NOTHING IS BUILT. Written on paper on 2026-10-10 against the Phase 2, 3 and 4 plans and the Phase 5 plans: 05-01 (friends, blocks, the visibility rule, the one migration 0007, the social test tools), 05-02 (the Board, posts, reactions, comments, the one photo-link function, the friends count), 05-03 (the derived notification list and the seen time), 05-04 (the Friends screen and the Friends number on Profile, the friends API calls and error codes), 05-05 (the Board, a friend's post page, the reaction row, comments, the additions to your own entry page, the bar of five) and 05-06 (the notification list in the app, the bell dots, the cutover, the gates, the walkthrough, the close-out). Go tests run only on a database whose name ends in `test` (`rndmroll_test`), with `-p 1`. There is no JS test runner (two throwaway node scripts, `scripts/check-board.ts` and `scripts/check-notifications.ts`, check the pure logic), so screen checks are device steps in `05-06-PLAN.md` Task 3 ('group done' or what looked wrong).
