# Phase 2.1: Validation Map (Settings)

> How each behaviour is proven. Nothing is built yet. Go tests run only on a database whose name ends in `test` (`rndmroll_test`), with `-p 1`. There is no JS test runner (a throwaway node script checks the pure rules), so screen checks are device steps in `02.1-02-PLAN.md` Task 4 ("group done" or what looked wrong). The four real dev accounts are never touched.
