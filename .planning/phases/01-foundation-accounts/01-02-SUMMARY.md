## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] `npx tsc --noEmit` failed with "No inputs were found" at the end of Task 1**
- **Found during:** Task 1, running the task's own acceptance-criteria verification
- **Issue:** With no `app/` directory (explicitly forbidden by this task) and no `lib/` yet (Task 2's job), there were zero `.ts`/`.tsx` files anywhere in the repo for `tsc`'s `include` glob to match, so the compiler had no input and exited with `TS18003`.
- **Fix:** Created `expo-env.d.ts` at the repo root with Expo's standard ambient-types content (`/// <reference types="expo/types" />`), which is normally auto-generated by `expo start`/`expo customize` on first run. This file is included via the explicit `expo-env.d.ts` entry in `tsconfig.json`'s `include` array (copied from the scaffold's own tsconfig).
- **Files modified:** `expo-env.d.ts` (created, left untracked — see Decisions above)
- **Verification:** `npx tsc --noEmit` exits 0 after the fix
- **Committed in:** not committed (intentionally untracked generated file, consistent with the file's own header comment)

**2. [Rule 1 - Bug] Scaffold's `app.json` would have broken `expo config` if copied verbatim**
- **Found during:** Task 1, before writing `app.json`
- **Issue:** The scaffold's `app.json` references `./assets/images/icon.png`, adaptive-icon images, and a splash-screen image under `assets/` — but Task 1's instructions explicitly exclude copying the scaffold's `assets/` directory (later plans own real brand assets; the project's Launch Gate explicitly defers favicon/icon work to a future milestone). Copying `app.json` as-is and only patching the fields the plan lists would have left it pointing at nonexistent image files.
- **Fix:** Hand-authored `app.json` with only the fields the plan specifies (name, slug, scheme, userInterfaceStyle lock, bundle identifiers, usesAppleSignIn, plugins) and no icon/splash-image references.
- **Files modified:** `app.json`
- **Verification:** `npx expo config --type public` renders cleanly with no errors or warnings about missing assets
- **Committed in:** `0679726` (Task 1 commit)
