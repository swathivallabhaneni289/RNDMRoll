<objective>
Scaffold the React Native / Expo SDK 57 application, lock its platform appearance to light, and translate UI-SPEC revision 8 into a single typed tokens module that every screen in this phase imports from.

Purpose: UI-SPEC revision 8 is an approved design contract with exact hex values, sizes, and shadow parameters. Encoding it once as typed tokens is what stops seven screens from each inventing their own values, and is what makes the phase's design constraints (no pill buttons, no chromatic accent) mechanically checkable.
Output: A typechecking Expo app with `lib/theme/tokens.ts`, `lib/theme/fonts.ts`, and platform config.
</objective>

  <action>
Create `lib/theme/tokens.ts` exporting five const objects plus a combined `tokens` object, all typed with `as const` so screens get literal types.

`color`: `dominant: '#F6F5F2'`, `secondary: '#E8E7E3'`, `card: '#FFFFFF'`, `ink: '#111111'`, `muted: '#625F5B'`, `divider: '#D3D0C9'`, `destructive: '#9A3B32'`, `success: '#416B4C'`. Add derived opacity helpers as string constants, not runtime math, so they stay greppable: `inkRest: 'rgba(17,17,17,0.15)'` (unfocused input border and unselected method outline), `inkInactive: 'rgba(17,17,17,0.2)'` (inactive step dots and icon-badge border), `inkDisabled: 'rgba(17,17,17,0.35)'` (disabled CTA fill), `inkAvatarPlaceholder: 'rgba(17,17,17,0.4)'`, `inkTexture: 'rgba(17,17,17,0.08)'`, `onInkDisabled: 'rgba(246,245,242,0.7)'` (disabled CTA label).

`space`: `xs: 4, sm: 8, md: 16, lg: 24, xl: 32, xxl: 48, xxxl: 64`. Add `minTouchTarget: 44` as a separate export-level constant with a comment that it is a hit-area floor, not a spacing step.

`radius`: `sm: 4, md: 8, lg: 24, full: 9999`. Document on `md` that it is the hard maximum for anything tappable, and on `lg` that it is permitted only on the profile-view container card and the log-out confirmation sheet. Document on `full` that it exists solely for the circular avatar and icon-badge tokens and must never be applied to a button, input, or chip.

`type`: five roles, each an object with `fontSize`, `lineHeight`, and `fontFamily`. `body: {16, 24, 'WorkSans_400Regular'}`, `label: {14, 20, 'WorkSans_400Regular'}`, `button: {16, 24, 'WorkSans_600SemiBold'}`, `heading: {22, 28, 'Domine_600SemiBold'}`, `display: {40, 46, 'Domine_600SemiBold'}`. Do not add a numeric `fontWeight` to any role: UI-SPEC's platform note states that combining a custom `fontFamily` with a separate `fontWeight` makes Android's font matcher silently fall back to the family default weight.

`elevation`: three tiers matching UI-SPEC's Elevation table exactly. `subtle: { backgroundColor: color.secondary, elevation: 0 }` with no shadow keys at all. `card: { backgroundColor: color.card, shadowColor: color.ink, shadowOffset: {width: 0, height: 2}, shadowOpacity: 0.08, shadowRadius: 6, elevation: 3 }`. `raised: { backgroundColor: color.ink, shadowColor: color.ink, shadowOffset: {width: 0, height: 4}, shadowOpacity: 0.18, shadowRadius: 10, elevation: 6 }`. Every `shadowColor` is `color.ink`, never a literal black.

`texture`: `dotDiameter: 2`, `dotColor: color.inkTexture`, `spacing: 16`.

Create `lib/theme/fonts.ts` exporting `useAppFonts()` which calls `useFonts` from `expo-font` with exactly three families: `Domine_600SemiBold` from `@expo-google-fonts/domine`, and `WorkSans_400Regular` plus `WorkSans_600SemiBold` from `@expo-google-fonts/work-sans`. It returns `{ fontsLoaded: boolean, fontError: Error | null }`. Also export `systemFallback` mapping each of the five type roles to a platform system font at weight 400 or 600, used only in the font-error branch as UI-SPEC's platform note specifies.

Create `lib/theme/tokens.test-assert.ts` as a compile-time contract file: import the tokens and write `const _assertions` entries that pin the values other plans depend on, for example a `satisfies` expression asserting `radius.md` is `8` and `type.display.fontSize` is `40`. This file is never imported at runtime; it exists so `tsc --noEmit` fails loudly if a later plan edits a token another plan relies on.
  </action>
