| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Long dense messages | The developer dictates by voice, said a dense report was confusing, and asked "why did we suddenly go to Safari?" about a step never explained | blocking | Short plain messages, a few steps at a time; say WHY before a step that leaves the app (Safari, Settings, relaunch); give lettered choices when a reference is not visible to you |
| `git add -A` or `git add .` | Would ship `app/lab/`, `docs/reference/`, `.claude/` (nested worktree with node_modules) | blocking | Stage explicit paths only |
| Building before a go | GSD auto mode is OFF on purpose; walkthroughs are the developer's | blocking | Write the plan, get an explicit go, then build |
| Driving the simulator unasked | It is the developer's UAT device and Claude cannot tap or type | advisory | Only relaunch and screenshot (passive), and say so |
| Code edits mid-signup | A reload drops the in-memory draft | advisory | Edit at a boundary, or when the developer asked for the change |
