## Lessons from 2026-10-09 (read these)

- A terse screenshot complaint ("its all empty", "like this", "the password is not added after the username") was guessed wrong three times. One concrete example with real values settled the design. Ask one plain question with an example before building.
- A hot update can silently not reach the phone. Take a screenshot after every app edit; restart the app at a boundary if nothing changed, and say so.
- The developer hates typing in tests. Use accounts made through the API and keep checks short.
- Adding a nullable column is backward compatible: migrate the dev database BEFORE restarting the API. The API does not migrate itself (`~/go/bin/migrate`). To undo a migration whose files are gone, copy the files to a temp folder and run `down 1` there.
- Another iOS system prompt ("Save Password?") can appear when a form with password boxes reloads: tap Not Now.
