<binding_decisions>
Final.
1. `02-UI-SPEC.md` is the design. Every string comes from its sections 10 and 11. This plan adds none. Strings say "spin", never "roll".
2. The landing is `/(app)/today`, an explicit child path, never a bare `/(app)`. The one exception is first run (decision 11): `app/index.tsx` sends to `/(app)/profile` while `extrasPending` is true.
3. Home is a Stack inside a tab: Today, then Edit wheel. The bottom bar stays on Edit wheel. The editor guards every way out (Back, the iOS swipe, a Home or Spin tab press that pops the stack) with a `beforeRemove` listener that opens the leave sheet, and sets `gestureEnabled: false` while changes are unsaved. Save is pinned above the bar and the keyboard. The Profile tab keeps its own Stack.
4. The middle Spin button never becomes the selected tab. It goes to Today and sets `pendingSpin` in `todayStore`. Today consumes it (sets it false) only after the focus refetch has settled and the state is `open`; if not open it is cleared and nothing spins. No timer and no route parameters. The leave sheet clears it too.
5. Today asks the server again: on mount, on tab focus (so a moved test clock shows), on foreground, when a countdown reaches zero, and at the server's `next_open_at` and close time in every state that has one (nearest first, re-armed after each fetch). If the answer at zero still says waiting, ask again after 1 second, at most 5 times. While the wheel turns, triggers are ignored and one refetch runs when it lands. After `spin_closed` or `spin_not_open` Today refetches and shows the message once; "Try again" for those two is a refetch, not a new POST (only a network failure re-sends the same request). A failed refetch with data on screen keeps the screen and retries once after 5 seconds.
6. The countdown counts from the server's `now` with `performance.now()` (monotonic), marked when the request starts, never the phone's clock. On foreground the anchor is dropped and the Loading digits show until the refetch succeeds.
7. `lastReportedZone` lives in memory. The phone reports its time zone on mount, on foreground and when `deviceTimeZone()` differs from it, never on tab focus (the server limits reports to 20 a minute). A failed report does not block Today (the server uses the stored zone) and is retried on the next trigger. If the zone cannot be read, the plain "Something went wrong" message shows.
8. "Save wheel" is one `PATCH` of the whole list. The client has no DELETE and gets none.
9. `app/_layout.tsx`, `app/(auth)/_layout.tsx` and `lib/session/store.ts` are not edited (the store is only read, through `useSession()`). If a cold launch shows one must change, stop and ask the developer first.
10. Round shapes (UI-SPEC section 8): the header photo is a circle through `DialAvatar` (a named avatar exception, confirmed by the developer on 2026-10-08); the visible hub is a drawn circle with a transparent 64dp square (8dp radius) as the tap area; the Spin button is an 8dp square. No pills.
11. First run (UI-SPEC sections 1, 8, 9). Phase 1's photo-and-bio page (`ProfileForm` mode `extras`, rendered by `app/(app)/profile/index.tsx` while `extrasPending` is true) is kept as it is. `app/index.tsx` reads `extrasPending` from `useSession()` and redirects to `/(app)/profile` while it is true and to `/(app)/today` otherwise; this one route also runs after every sign-in, because the root Stack puts `index` back when `(auth)` leaves (checked in the installed router, `StackRouter.getStateForRouteNamesChange`). The bottom bar is hidden on that page: the `profile` screen's options carry `tabBarStyle: { display: 'none' }` while `extrasPending` is true (the bar reads the focused route's options). Continue (after its save) and Skip for now call `router.navigate('/(app)/today')` first and `finishExtras()` second, in the same function, so the edit page never flashes. Nothing else sets or clears the flag. A relaunch shows Today (the flag is in memory only). If a person ever reaches Today with the flag still set, nothing breaks: the bar shows on Today (the hide applies to the profile screen only), and the Profile tab shows the page once more until Continue or Skip for now clears it.
12. Placeholder page. `app/(app)/home.tsx` (Phase 1's "You're in." page) is deleted in Task 3 and nothing links to `/home`. The Profile page's bottom button in edit mode keeps its label "Continue" while nothing has changed, and now goes to `router.navigate('/(app)/today')`.

**c. Pure logic** (no React, no app imports, so each file reads on its own). Angles are degrees clockwise from 12 o'clock, and a positive rotation turns the disc clockwise.
- `geometry.ts`: `drawnAngles(weights)` (true angle `360 x weight / total`, floor 22 degrees, redistribute until none is under 22); `wedgePath(a0, a1, r)` = `M 0 0 L polar(a0) A r r 0 {large} 1 polar(a1) Z` with the large-arc flag `{large}` = 1 when `a1 - a0 > 180`, else 0 (weights 10 and 1 draw a wedge near 327 degrees); `polar` copied from `BrandMark.tsx`; `toneIndexes(n)` (UI-SPEC 2 table, written as the fixed table for counts 2 to 12); `labelColorFor(tone)` (tones 1 and 2 `dominant`, 3 to 6 `ink`); `poseOf(centre)` = `-centre` (the rotation that brings that centre to 12 o'clock); `targetRotation(current, pose)` = `ceil((current + 1800 - pose) / 360) x 360 + pose`, always called with the winner's pose, and the rest rotation is the pose of the shown wedge (the first wedge with no spin); `wedgeUnderPointer(rotation, angles)` = the wedge containing `(360 - rotation mod 360) mod 360`; `labelFlip(centre, finalRotation)` = true when `(centre + finalRotation) mod 360` is between 180 and 360 (so the word reads upright in the pose it stops in); `labelLine`, `truncate(name, n)`, `sharePercent(weights)` (true shares, whole numbers).

- `timeZone.ts`: `deviceTimeZone()` returns `Intl.DateTimeFormat().resolvedOptions().timeZone` or null.
- `todayStore.ts`: a module store (`useSyncExternalStore`) holding the latest `Today`, `spinning` and `pendingSpin`, keyed by the signed-in user id: any read or write under another id discards the old data first, a response whose request began under another id is dropped, and `lastReportedZone` is part of it.
