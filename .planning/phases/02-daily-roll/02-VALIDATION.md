# Phase 2: Validation Map (Daily Roll, "the spin")

> How each behaviour is proven. Built and closed on 2026-10-13 with open device checks: the Status column of the Map says which rows are proven and which are not (details in `02-03-SUMMARY.md`). Rebased on the final Phase 1 code (main tree commit ead0c70) on 2026-10-09. Revised later that day: Phase 1 removed Apple and Google sign-in completely, so the database is at version 3 before Phase 2 starts and Phase 2's migration is 0004. Revised on 2026-10-10 (UI-SPEC revision 5): the Today screen follows the developer's new picture, `docs/reference/today-screen-1a-1b-2026-10-10.png`, layout 1a, so the wheel tones, the bell and its page, the Spin button looks, the week section and the type rows below changed. Revised again on 2026-10-10 (revision 6): after the spin the wheel is gone and the word fills the screen with the time it was spun (`docs/reference/today-after-spin-02-2026-10-10.png`), the server writes that time and the next open's weekday, and three more text roles were added. Revised again on 2026-10-10 (revision 7, D-23): every category has the same chance, Edit wheel shows no numbers, and the wheel has no grey wedge (seams between all wedges), so one colour pin is gone. Revised later on 2026-10-10 (D-24): the bar has five items with Diary and Board as plain pages, and the Spin button is a 64dp light grey circle while locked, so the `ls "app/(app)"` check and the Spin button rows changed. Revised again on 2026-10-10 (revision 9, D-25): the wheel is finer and its dark tone is the new token `wheelCharcoal`, so one colour pin is added and the raw hex scan finds that one new value in the two token files, nothing else. Superseded on 2026-10-13 (D-26, commit `b8729fd`): the dark tone is `ink` again and the `wheelCharcoal` token and its pin are removed, so read every `wheelCharcoal` below as `ink`. Go tests run only on a database whose name ends in `test` (`rndmroll_test`), with `-p 1`. There is no JS test runner (a throwaway node script checks the pure wheel logic), so screen checks are device steps in `02-03-PLAN.md` Task 3 ("group done" or what looked wrong).
